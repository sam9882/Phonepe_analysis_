# Phonepe_analysis_# 📊 Total Transaction Summary – PhonePe

## 📌 Project Overview
This project focuses on analyzing PhonePe transaction data and creating a **Total Transaction Summary** using Power BI. The dashboard converts raw transaction data into meaningful insights through KPIs, charts, and interactive filters.

## 🎯 Objectives
- Analyze total transaction volume and transaction value
- Track transaction trends over time
- Compare successful and failed transactions
- Analyze transaction performance by service
- Understand user transaction behavior
- Identify key business insights from payment data

## 🛠️ Tools & Technologies
- Power BI
- DAX
- Microsoft Excel
- Data Cleaning
- Data Visualization

## 📊 Dashboard Highlights
- Total Transactions
- Total Transaction Value
- Unique Users
- Successful Transaction Rate
- Monthly Transaction Analysis
- Service-wise Transaction Value
- Payment Status Analysis
- Top Users by Transaction Value
- Weekday vs Weekend Usage
- Age Segment Analysis

## 📁 Project Workflow
1. Imported raw transaction data
2. Cleaned and transformed the dataset
3. Created calculated columns and DAX measures
4. Built KPIs for transaction analysis
5. Created interactive charts and visualizations
6. Added filters and slicers
7. Designed the final Power BI dashboard
8. Analyzed the results and generated business insights

## 💡 Key Outcome
The project demonstrates how **Power BI, DAX, and data visualization** can be used to transform payment transaction data into an interactive business intelligence dashboard.## 📸 Dashboard Preview
